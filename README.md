# To-Do List Application

A modern, feature-rich to-do list application with local storage functionality. Built with vanilla HTML, CSS, and JavaScript.

## 🎯 Features

### Core Functionality
- ✅ **Add Tasks** - Quickly add new tasks with input validation
- ✅ **Mark Complete** - Check off tasks as you complete them
- ✅ **Edit Tasks** - Update task descriptions anytime
- ✅ **Delete Tasks** - Remove individual or all tasks
- ✅ **Local Storage** - All tasks are automatically saved to browser storage

### Filtering & Organization
- 🔍 **Filter by Status** - View All, Active, or Completed tasks
- 📊 **Statistics Dashboard** - Real-time count of total, active, and completed tasks
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile

### Advanced Features
- 🗑️ **Bulk Operations** - Clear all completed tasks or clear everything
- 📥 **Export Tasks** - Download tasks as JSON file for backup
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- ⚡ **Fast & Efficient** - No server required, everything happens locally
- 🔒 **Data Privacy** - All data stored locally on your device

## 📝 How to Use

### Adding Tasks
1. Type your task in the input field
2. Press Enter or click "Add Task"
3. Task is automatically saved to local storage

### Managing Tasks
- **Complete**: Check the checkbox next to a task
- **Edit**: Click the "✎ Edit" button and update the task
- **Delete**: Click the "✕ Delete" button to remove a task

### Filtering
- Click filter buttons to view:
  - **All**: Shows all tasks
  - **Active**: Shows only incomplete tasks
  - **Completed**: Shows only completed tasks

### Bulk Actions
- **Clear Completed**: Removes all completed tasks
- **Clear All**: Removes all tasks
- **Export Tasks**: Downloads tasks as JSON file

## 💾 Local Storage

The application automatically saves all tasks to your browser's local storage. This means:
- Tasks persist even after closing the browser
- No server or internet connection required
- Each browser/device has its own task storage
- Storage limit is typically 5-10MB per domain
